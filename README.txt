PROYECTO EVALUACIÓN UNIDAD III - PYTHON Y FLASK

EJECUCIÓN EN WINDOWS
1. Descomprime el ZIP y abre la carpeta Proyecto_Flask_Evaluacion.
2. En la barra de dirección del Explorador escribe cmd y presiona Enter.
3. Ejecuta estos comandos, uno por uno:

python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py

4. Abre http://127.0.0.1:5000 en el navegador.

El ejercicio 1 calcula el promedio de tres notas y aprueba solo si el promedio
es >= 40 Y la asistencia es >= 75%.
El ejercicio 2 muestra el nombre o nombres con mayor cantidad de caracteres.

Después de crear el repositorio en GitHub, copia su URL real en ENLACE_GITHUB.txt.
